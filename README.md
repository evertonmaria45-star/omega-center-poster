# Omega Center Poster — Site oficial do aplicativo TikTok

Site público do aplicativo **Omega Center Poster** (TikTok for Developers, app id
7696942063186790420), da OMEGA CENTER. Hospedado no GitHub Pages.

O aplicativo é uma ferramenta interna que **publica vídeos somente nas contas TikTok
do próprio dono** e **lê estatísticas** dessas mesmas contas (Content Posting API +
Login Kit).

## Páginas

- `index.html` / `index-en.html` — página principal (português / inglês)
- `privacidade.html` / `privacy.html` — Política de Privacidade
- `termos.html` / `terms.html` — Termos de Uso
- `icon.png` — ícone do aplicativo (1024x1024)

## Verificação de URL do TikTok

Quando o portal do TikTok Developers gerar o token de verificação, adicioná-lo no
`<head>` do `index.html` (meta tag) e/ou publicar o arquivo de verificação na raiz
do repositório, conforme o método indicado pelo portal.
